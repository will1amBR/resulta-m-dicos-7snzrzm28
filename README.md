# Resulta Médicos

Plataforma Unificada de Gestão Clínica, Prontuário Eletrônico, Prescrições Digitais e Teleconsulta em conformidade com a LGPD e normas do CFM.

## 🚀 Stack Tecnológica

- **React 19** - Biblioteca JavaScript para construção de interfaces modernas
- **Vite** - Build tool ágil e otimizada
- **TypeScript** - Tipagem estática e segurança de código
- **Shadcn UI & Tailwind CSS** - Componentes reutilizáveis, acessíveis e design responsivo
- **React Router** - Roteamento SPA
- **PocketBase** - Backend leve, autenticação e banco de dados em tempo real

## 💻 Scripts Disponíveis

### Desenvolvimento
```bash
npm start
# ou
npm run dev
```

### Build para Produção
```bash
npm run build
```

### Qualidade e Linting
```bash
npm run lint
npm run format
```
